# Labyrinth

## Online
This project is online at https://tilde.town/~nossidge/labyrinth/


## Background
This project is my attempt to create something similar to Superbad.com, the internet art website
created in 1997 by Ben Benjamin.

I really love Superbad. It's one of the first websites I can remember visiting and truly adoring,
and even back then in those early days of web experimentation, there wasn't much else like it. It
contains 265 surreal little web pages that link to each other in a maze of hyperlinks, and I used to
love clicking around and seeing all the weird and wonderful things. I consider it to be a true
masterpiece of early web art.


## Project description
My version takes the same concept of mostly self contained individual web pages, but adds more
procedural generation and JavaScript interaction. Most pages link to each other at random, so when
the user is clicking around they will not know what's going to come next. This lack of restriction
lets me be free to create whatever I want, and as long as the page contains at least one hyperlink
it can be easily added to the pool of labyrinth pages.


## My goal
My goal for this project is to challenge myself to make one tiny little arty web page every day
throughout 2026.

The philosophy for this was "quantity over quality". Just make something interesting and shove it
out there. Each individual page doesn't need to be perfectly polished, because the user always knows
there'll be something different just a click away.

And there is wheat in this chaff, I promise! Some of these pages are great!
